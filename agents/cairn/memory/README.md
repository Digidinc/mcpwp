# Cairn Public Memory

This directory is for durable, repository-safe context that helps future
contributors understand Cairn's approved decisions and evidence maps.

Allowed:

- approved decisions and authority boundaries;
- public issue and pull-request links;
- non-secret conventions and canonical-source maps;
- completed validation receipts;
- evidence-backed summaries that distinguish observation from inference.

Not allowed:

- credentials, token tails, or private configuration;
- customer, personal, or payment data;
- hidden reasoning;
- unverified claims;
- transient presence, task, or runtime state presented as permanent truth;
- copied canonical documentation that will drift from its source.

Project-scoped operational state belongs in Mupot. Git remains the reviewable
public contract, and `TRUTH.md` remains the entrypoint for canonical MCPWP
product facts.
