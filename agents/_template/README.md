# Example Agent Home

Rename this directory to the agent's stable lowercase slug. Replace the example
identity in every file before requesting import or project membership.

## Files

- `CHARTER.md`: mission, owned surfaces, gates, and prohibited actions.
- `SETUP.md`: owner-approved enrollment and verification checklist.
- `mupot-agent.yaml`: declarative Mupot import proposal.
- `assets/README.md`: canonical visual-asset inventory and provenance.
- `memory/README.md`: public, repository-safe memory rules.

## Completion standard

The home is ready for review when:

- its slug is stable and unique;
- all requested capabilities are narrow and justified;
- no credential or private data is present;
- the manifest parses as YAML;
- owned repository paths exist;
- a project owner has approved membership and authority separately;
- the first Mupot task and draft pull request are linked.
