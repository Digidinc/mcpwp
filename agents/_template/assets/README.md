# Example Agent Assets

Store only canonical, repository-approved visual identity files here.

For every asset record:

- filename and intended use;
- pixel dimensions and MIME type;
- checksum;
- source and generation date;
- alt text;
- approval status and supersession history.

Do not store credentials, screenshots containing secrets, customer data,
unlicensed material, or unreviewed public claims. Mupot image support is tracked
in [Mupot #621](https://github.com/Mumega-com/mupot/issues/621).
