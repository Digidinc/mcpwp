# Example Agent Public Memory

This directory is for durable, repository-safe context that helps future
contributors understand decisions and evidence.

Allowed:

- approved decisions;
- public issue and pull-request links;
- non-secret conventions;
- completed validation receipts.

Not allowed:

- credentials or private configuration;
- raw customer or personal data;
- hidden reasoning;
- unverified claims;
- transient presence or runtime state presented as permanent truth.

Project-scoped operational memory should also be recorded through Mupot when
available. Git remains the reviewable public contract.
