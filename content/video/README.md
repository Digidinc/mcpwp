# MCPWP Video Marketing Unit

This directory is the durable operating surface for MCPWP video work. It turns
verified product evidence into reviewable briefs, scripts, productions,
distribution packages, and receipts.

## Operating identity

The unit is directed by **Lumen**, Mupot agent `lumen-video-director`, inside the
`MCPWP Core` squad. Lumen operates with draft autonomy. A human remains
accountable for publishing, outreach, spending, live recording, and commercial
claims.

## Workflow

1. **Task:** Begin with a Mupot task that names the owner, audience, outcome,
   acceptance criteria, and approval gate.
2. **Brief:** Record authoritative sources, current product truth, prohibited
   claims, target formats, and measurement.
3. **Script:** Separate verified facts, captured demonstrations, narration,
   planned visuals, and calls to action.
4. **Production:** Use Remotion for reproducible programmatic video or an
   approved OBS scene specification for real footage.
5. **Review:** Render a draft and obtain an explicit human verdict.
6. **Distribution:** Prepare channel copy and scheduling instructions without
   publishing automatically.
7. **Evidence:** Retain the source commit, render identity, reviewer, verdict,
   publication destination, and measured outcome.

## Directory map

| Directory | Responsibility |
| --- | --- |
| `agents/` | Role, authority, and escalation contracts |
| `briefs/` | Audience, objective, sources, claims, and acceptance criteria |
| `scripts/` | Narration, shots, on-screen copy, and evidence mapping |
| `remotion/` | Programmatic-video composition conventions |
| `obs/` | Human-controlled recording and scene specifications |
| `assets/` | Provenance and approval rules for visual and audio assets |
| `distribution/` | Channel packages and publishing gates |
| `evidence/` | Completion and publication receipts |

## Truth and safety

- Prefer current release behavior, release notes, WordPress.org material, and
  verified demonstrations over old marketing copy.
- Label planned, beta, unavailable, and third-party behavior explicitly.
- Do not place credentials, cookies, API keys, customer data, private account
  identifiers, or unredacted dashboards in source or rendered media.
- A successful render is not publication proof.
- Name working files `YYYY-MM-DD-topic-purpose.md` so Mupot tasks and Git
  history can identify them consistently.
